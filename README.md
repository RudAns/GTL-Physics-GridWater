# 《海狸浮生记》的网格水

从城建游戏《海狸浮生记》（Timberborn，Mechanistry 开发）的水系统到 UE5：技术调研 + UE 5.8 可交互复现。

[![调研报告封面](Docs/shots/00_research_cover.png)](Docs/Research.html)

## 调研报告

**[Docs/Research.html](Docs/Research.html)**：单文件网页，约 15,000 字，48 条中、日、韩、英、波兰语文献，带 2 个交互示意，下载后用浏览器打开。

报告依据开发者的技术专栏、公开的程序集反射数据与配置蓝图、历次更新说明和多语种玩家实测，还原了游戏的水流、干旱蒸发、灌溉与 2024 年加入的恶水潮，并与《矮人要塞》、From Dust、《城市：天际线》和浅水方程等方案对比。主要结论：

- 水流基于虚拟管道法（Mei 等，2007），游戏在此基础上加了 0.999 阻尼、软硬坝、漫流阈值等面向玩法的改动；Update 6 的“三维水”是每格多段水柱，不是体素流体。
- 恶水是一个浓度标量，随净流量做一阶迎风平流，只在近静水界面扩散。截流和导流有效，是因为阻断水流就阻断了污染的主要输运途径。
- 蒸发和灌溉共用“聚簇饱和度”这个水面大小度量，用 3×3 局部计数代替全图连通区域搜索。
- 可改进之处：污染物与水量使用同一通量以严格守恒、门控扩散改为平滑权重、阻尼改为半隐式摩擦。模拟计算量很小，手游可行。

## 技术落地文档

**[Docs/Implementation.html](Docs/Implementation.html)**：按数据流顺序整理数据布局、子步流水线、建筑约束、季节曲线、派生场、水面渲染和自测方法，附关键常数、坑点清单和移植清单，示意图内嵌，可以直接对照源码搬进自己的项目。

## UE 5.8 可交互 Demo

一个可交互的河谷水系模拟：用堤坝、大坝、防洪闸、自动阀和水泵改造河流与水库，观察干旱和恶水潮中水流、污染与灌溉的变化。右侧“原理实验室”可以逐项切换原作做法与报告提出的改进方案，左下角水量账本实时显示守恒误差，七种调试视图展示水深、流速、污染度、饱和度、湿度和土壤污染。

![总览](Docs/shots/01_overview.png)

### 运行

1. 用 UE 5.8 打开 `GridWater.uproject`（首次打开会编译 C++ 模块）后点 Play；或编译后双击 `Run.bat` 以独立窗口运行。
2. 默认地图 `/Game/Maps/Valley` 是空关卡，河谷地形、河道、水库、农田、植物和灯光都由 `AGWWorld` 在运行时生成。开局会先在后台快进 4 天，让河流、水库和灌溉稳定下来。

### 模拟内容

季节按“温和季 4 天 → 危险季 2 天（干旱或恶水潮）”循环，演示里 1 天等于 60 秒模拟时间，×1 速度下约 20 秒。

- **恶水潮**：所有水源的污染度从 50% 起，半天内沿双曲正割曲线升到 100%。污染随水流推进，分叉口预置的自动阀在上游污染度超过阈值时关闭，把恶水导向南支。没有保护的南边农田会被土壤污染毁掉。
- **干旱**：水源在开始前半天逐渐减弱到 0，蒸发继续；浅滩先干，灌溉范围从外向内收缩，缺水的作物和树木枯萎。
- 新的温和季开始时，海狸会把死去的作物和树补种回来。
- 相邻的同类水利建筑自动连成一排，共用立柱和闸板；查看模式下点击可以选中整排，统一调整高度或阀门模式。

### 代码结构

| 位置 | 内容 |
|---|---|
| `Source/GridWater/WaterSim` | 纯 C++ 水模拟：每个子步依次做出流（虚拟管道、0.999 阻尼、K 缩放、软硬坝、漫流阈值、方向限制）、水深与蒸发、污染平流、门控扩散，均用 `ParallelFor` 按行并行；每 tick 更新聚簇饱和度、蒸发倍率、灌溉湿度、土壤污染。系数取自报告引用的 Update 6 时期配置 |
| `Source/GridWater/GWWorld` | 场景与模拟流程：河谷生成、地形网格、水面网格、数据纹理上传、季节与水源曲线、建筑约束与外观、植物与装饰 |
| `Source/GridWater/GWPlayerController` | 输入、拾取、建造、原理开关与参数、自测脚本（`-GWCapture=<目录>`） |
| `Source/GridWater/GWHud` | 代码构建的 UMG 界面：状态卡片、季节时间轴、建造栏、原理实验室、水量账本、格子信息、视图图例、开局卡片 |
| `Source/GridWater/GWCamera` | 城建镜头：45° 一档旋转、缩放联动俯仰角 |
| `Tools/build_assets.py` | 无头生成材质（水面 WPO、地形、建筑、天空、道具）、导入 KayKit 道具、建空地图。HLSL 写在脚本里便于审阅 |
| `Tools/iterate.ps1` | 编译 → 可选重建资产 → 离屏自测与截图 |

水面是一张静态网格：每格一个顶面和四个侧面，顶点高度由材质的世界位置偏移从数据纹理读取（R 水面或地面高度、G 水深、B 污染度、A 聚簇饱和度；另一张存流速、湿度、土壤污染），在相邻两次模拟结果之间插值。侧面只在相邻格水面更低时展开，自然形成瀑布。

### 自测

`powershell -File Tools/iterate.ps1` 会编译、离屏运行并执行 34 项自测，全部通过注入的键鼠事件完成：Enter 开局、R / Shift+R 旋转 45°、Z 旋转建筑朝向、滚轮缩放、WASD 平移、鼠标悬停拾取、左键放防洪闸、[ ] 调高闸门、拖动建堤坝、X 拆除、点击选中一整排阀门并用 M 切换三种模式、相邻防洪闸自动同步高度并整排调高、F1–F7 切换与还原、V 视图、Space/Tab 速度、挖掘与堆土、恶水潮中自动阀关闭且水库污染度保持 0%、默认设置下水量守恒误差约 0.002、关闭 K 缩放后误差明显增长。另外会在暂停状态下对瀑布近景隔 0.3 秒截两帧，用于比对台阶处是否闪烁。截图保存在 `Saved/Capture`，日志中搜索 `GWTEST`。
