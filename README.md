# GTL-Physics-GridWater

《海狸浮生记》（Timberborn）网格水系统的交互复现（UE 5.8，C++）。对应 GameTech-Lab 调研报告《海狸浮生记的水系统：网格水流、干旱蒸发与恶水潮》，按报告第 11 章的方案实现：多层水柱简化为单层的虚拟管道法、恶水污染度的平流与门控扩散、按水深分档的蒸发与聚簇饱和度、灌溉湿度与土壤污染，以及大坝、防洪闸、自动阀等水利建筑。原作做法和报告提出的改进方案都可以在游戏里逐项切换对比。

![总览](Docs/shots/01_overview.png)

## 运行

1. 用 UE 5.8 打开 `GridWater.uproject`（首次打开会编译 C++ 模块）后点 Play；或编译后双击 `Run.bat` 以独立窗口运行。
2. 默认地图 `/Game/Maps/Valley` 是空关卡，河谷地形、河道、水库、农田、植物和灯光都由 `AGWWorld` 在运行时生成。开局会先在后台快进 4 天，让河流、水库和灌溉稳定下来。

## 玩法

开局卡片说明目标：撑过 3 个危险季，水库污染度保持在 5% 以下，农田作物存活率不低于 80%。季节按“温和季 4 天 → 危险季 2 天（干旱或恶水潮）”循环，演示里 1 天等于 60 秒模拟时间，×1 速度下约 20 秒。

- **恶水潮**：所有水源的污染度从 50% 起，半天内沿双曲正割曲线升到 100%。污染随水流推进，分叉口预置的自动阀在上游污染度超过阈值时关闭，把恶水导向南支。没有保护的南边农田会被土壤污染毁掉。
- **干旱**：水源在开始前半天逐渐减弱到 0，蒸发继续；浅滩先干，灌溉范围从外向内收缩，缺水的作物和树木枯萎。
- 新的温和季开始时，海狸会把死去的作物和树补种回来。

## 代码结构

| 位置 | 内容 |
|---|---|
| `Source/GridWater/WaterSim` | 纯 C++ 水模拟：每个子步依次做出流（虚拟管道、0.999 阻尼、K 缩放、软硬坝、漫流阈值、方向限制）、水深与蒸发、污染平流、门控扩散，均用 `ParallelFor` 按行并行；每 tick 更新聚簇饱和度、蒸发倍率、灌溉湿度、土壤污染。系数取自报告引用的 Update 6 时期配置 |
| `Source/GridWater/GWWorld` | 场景与玩法：河谷生成、地形网格、水面网格、数据纹理上传、季节与水源曲线、建筑约束与外观、植物与装饰 |
| `Source/GridWater/GWPlayerController` | 输入、拾取、建造、原理开关与参数、自测脚本（`-GWCapture=<目录>`） |
| `Source/GridWater/GWHud` | 代码构建的 UMG 界面：目标、季节时间轴、建造栏、原理实验室、水量账本、格子信息、视图图例、开局卡片 |
| `Source/GridWater/GWCamera` | 城建镜头：45° 一档旋转、缩放联动俯仰角 |
| `Tools/build_assets.py` | 无头生成材质（水面 WPO、地形、建筑、天空、道具）、导入 KayKit 道具、建空地图。HLSL 写在脚本里便于审阅 |
| `Tools/iterate.ps1` | 编译 → 可选重建资产 → 离屏自测与截图 |

水面是一张静态网格：每格一个顶面和四个侧面，顶点高度由材质的世界位置偏移从数据纹理读取（R 水面或地面高度、G 水深、B 污染度、A 聚簇饱和度；另一张存流速、湿度、土壤污染），在相邻两次模拟结果之间插值。侧面只在相邻格水面更低时展开，自然形成瀑布。

## 自测

`powershell -File Tools/iterate.ps1` 会编译、离屏运行并执行 29 项自测，全部通过注入的键鼠事件完成：Enter 开局、R / Shift+R 旋转 45°、Z 旋转建筑朝向、滚轮缩放、WASD 平移、鼠标悬停拾取、左键放防洪闸、[ ] 调高闸门、拖动建堤坝、X 拆除、点击自动阀切换三种模式、F1–F7 切换与还原、V 视图、Space/Tab 速度、挖掘与堆土、恶水潮中自动阀关闭且水库污染度保持 0%、默认设置下水量守恒误差约 0.002、关闭 K 缩放后误差明显增长。截图保存在 `Saved/Capture`，日志中搜索 `GWTEST`。
